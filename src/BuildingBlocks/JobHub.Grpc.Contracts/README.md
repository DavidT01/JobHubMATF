# Shared gRPC contracts

Targets .NET 10. Both server bases and clients are generated by Grpc.Tools.

## Application integration

These additive contracts do not change existing CandidateProfile or Recruitment
RPCs, message fields or field numbers. Contract generation alone does not enable
an endpoint: Profile and Catalog must implement and map the new server bases
before Application switches from HTTP readers to gRPC.

- `ApplicationProfileGrpcService.GetCandidateByUserId`: Identity user ID to
  candidate profile UUID, matching user ID and current CV URL. An empty CV URL
  means there is no uploaded CV; Application decides whether submission is valid.
- `ApplicationProfileGrpcService.GetCompanyByUserId`: Identity user ID to company
  profile UUID and matching user ID. There is no company employee mapping.
- `CatalogJobGrpcService.GetJob`: Catalog ObjectId to job ID, company **profile**
  UUID, active flag and nullable expiration timestamp. Inactive and expired jobs
  are returned too; Application applies its submission/ownership rules.

Server implementations must return `InvalidArgument` for invalid identifiers and
`NotFound` for missing records, rather than successful empty responses. Profile
lookups must validate the forwarded caller's bearer token and requested user ID;
unauthenticated/unauthorized calls must return `Unauthenticated`/`PermissionDenied`.
Do not expose these profile references through an anonymous public gateway route.
Clients must propagate cancellation, use bounded deadlines, validate response IDs
and distinguish missing records from unavailable dependencies. No CV bytes, contact
details or other unrelated profile data are included in these lookup responses.

`expiration_date` uses protobuf message presence: absent means no expiration,
not the Unix epoch. A present timestamp is a UTC instant. Existing field numbers
must not be reused when evolving these contracts.

Build and regenerate C# contracts:

```sh
dotnet build src/BuildingBlocks/JobHub.Grpc.Contracts/JobHub.Grpc.Contracts.csproj --configuration Release
```
